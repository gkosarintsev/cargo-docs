# Внутренние сущности (Entities)

В данном разделе специфицированы внутренние сущности агрегатов (Entities) логистической платформы. Они обладают уникальным идентификатором (в рамках агрегата или глобально), изменяемым жизненным циклом и привязаны к родительскому агрегату.

## 1. Сущности агрегата Shipment (Груз/Заявка)

### `CargoItem` (Грузовое место)

Описывает конкретную единицу груза внутри перевозки.

- **Атрибуты**:
  - `id`: Уникальный идентификатор позиции.
  - `name`: Наименование груза.
  - `weight`: Вес (использует VO `Weight`).
  - `volume`: Объем (использует VO `Volume`).
  - `quantity`: Количество мест (целое число).
  - `dimensions`: Габариты - Д/Ш/В (использует VO `Dimensions`).
  - `packaging_type`: Тип упаковки (паллеты, коробки, мешки и т.д.).
  - `adr_class`: Класс опасности (использует VO `AdrClass`).
  - `temperature_range`: Температурный режим (использует VO `TemperatureRange`).
- **Методы**:
  - `update_dimensions(Dimensions)`: Обновить габариты груза.
  - `set_temperature_requirements(TemperatureRange)`: Задать температурный режим.

### `Stop` (Точка маршрута)

Точка погрузки, выгрузки, таможни или промежуточная остановка.

- **Атрибуты**:
  - `id`: Идентификатор точки.
  - `sequence_number`: Порядковый номер в маршруте (целое число).
  - `type`: Тип точки (`PICKUP`, `DELIVERY`, `CUSTOMS`, `WAYPOINT`).
  - `address`: Гео-адрес (использует VO `Address`).
  - `time_window`: Планируемое временное окно (использует VO `TimeWindow`).
  - `actual_arrival_time`: Фактическое время прибытия.
  - `actual_departure_time`: Фактическое время убытия.
  - `contact_person`: Контактное лицо на точке (ФИО, телефон).
- **Методы**:
  - `mark_arrived(timestamp)`: Зафиксировать прибытие.
  - `mark_departed(timestamp)`: Зафиксировать убытие.
  - `reschedule(TimeWindow)`: Изменить планируемое время.

## 2. Сущности агрегата Negotiation (Торги)

### `Offer` (Предложение)

Конкретная ставка, предложенная в рамках торгов.

- **Атрибуты**:
  - `id`: Идентификатор оффера.
  - `author_id`: Автор оффера (`Shipper` или `Carrier`).
  - `amount`: Предложенная ставка (использует VO `Money`).
  - `is_vat_included`: Включен ли НДС (boolean).
  - `expires_at`: Срок действия оффера (timestamp).
  - `comment`: Комментарий к предложению.
- **Методы**:
  - `accept()`: Принять оффер.
  - `reject()`: Отклонить оффер.
  - `is_expired()`: Проверить, не истек ли срок действия.

## 3. Сущности агрегата Fleet (Автопарк)

### `Driver` (Водитель)

Сотрудник транспортной компании, выполняющий рейс.

- **Атрибуты**:
  - `id`: Идентификатор водителя.
  - `full_name`: ФИО водителя.
  - `phone`: Контактный телефон.
  - `license_number`: Номер водительского удостоверения.
  - `categories`: Категории ВУ.
  - `experience_years`: Стаж работы (лет).
  - `passport_data`: Паспортные данные.
  - `user_account_id`: Привязанный аккаунт пользователя (User ID).
- **Методы**:
  - `update_license(new_license)`: Обновить данные ВУ.
  - `link_user_account(user_id)`: Привязать к учетной записи.

### `Trailer` (Прицеп / Полуприцеп)

Транспортное средство, предназначенное для перевозки груза.

- **Атрибуты**:
  - `id`: Идентификатор прицепа.
  - `license_plate`: Государственный регистрационный номер.
  - `body_type`: Тип кузова (использует VO `BodyType`).
  - `payload_capacity`: Грузоподъемность (использует VO `Weight`).
  - `useful_volume`: Полезный объем (использует VO `Volume`).
- **Методы**:
  - `update_registration(license_plate)`: Обновить госномер.

## 4. Сущности агрегата Document (Документ)

### `DocumentVersion` (Версия документа)

Конкретная ревизия файла документа.

- **Атрибуты**:
  - `id`: Идентификатор версии.
  - `version_number`: Номер версии (целое число, инкрементируется).
  - `s3_url`: Ссылка на файл в S3 хранилище.
  - `checksum`: Контрольная сумма файла (`SHA-256`).
  - `uploaded_by`: Автор загрузки (User ID).
- **Методы**:
  - `verify_checksum(hash)`: Сравнить хэш для проверки целостности.

### `Signature` (Электронная подпись)

Подпись, наложенная на документ.

- **Атрибуты**:
  - `id`: Идентификатор подписи.
  - `signature_type`: Тип подписи (`ПЭП` - простая, `КЭП` - квалифицированная).
  - `certificate_data`: Данные сертификата.
  - `timestamp`: Отпечаток времени наложения подписи.
  - `validation_status`: Статус валидации подписи (`VALID`, `INVALID`, `EXPIRED`).
- **Методы**:
  - `validate()`: Выполнить криптографическую проверку подписи.

## 5. Сущности агрегата Invoice (Счет/Инвойс)

### `InvoiceLineItem` (Позиция счета)

Отдельная строка в финансовом документе.

- **Атрибуты**:
  - `id`: Идентификатор позиции.
  - `description`: Описание услуги (фрахт, простой, доп. точка, штраф).
  - `amount`: Сумма (использует VO `Money`).
  - `vat_rate`: Ставка НДС (например, 20%, 0%, Без НДС).
- **Методы**:
  - `calculate_total()`: Рассчитать итоговую сумму с учетом НДС по позиции.
