# SMS — Шлюз SMS и мессенджеров

## Назначение

SMS-канал используется исключительно для сценариев с высокими требованиями к надёжности доставки, когда Push-уведомления и интернет-соединение ненадёжны или невозможны. Стоимость SMS-рассылки существенно выше остальных каналов, поэтому его применение строго регламентировано.

## Сценарии использования

| Сценарий                                    | Обоснование                                                                |
| ------------------------------------------- | -------------------------------------------------------------------------- |
| OTP-коды (2FA / авторизация)                | Криптографически значимое действие, требует независимого канала доставки   |
| Критические оповещения водителя             | Водители могут не иметь мобильного интернета в зоне покрытия только 2G/GSM |
| Аварийные ситуации в рейсе                  | Максимальная надёжность доставки при экстренных ситуациях                  |
| Просрочка оплаты (последнее предупреждение) | Юридически значимое уведомление                                            |

SMS **не используется** для: новых офферов, статусных обновлений в реальном времени, маркетинговых рассылок.

## Провайдеры и маршрутизация

### Основные провайдеры

| Провайдер      | Покрытие       | Приоритет             |
| -------------- | -------------- | --------------------- |
| SMSC.ru        | RU, KZ, BY     | Основной (RU)         |
| Stream Telecom | RU, KZ, BY, UA | Резервный (RU)        |
| Twilio         | Международный  | Основной (EU/Global)  |
| Vonage (Nexmo) | Международный  | Резервный (EU/Global) |

### Алгоритм выбора провайдера

```text
Определение кода страны из номера телефона (E.164)
  ├── +7 (RU/KZ)  → SMSC.ru
  │       ↓ (failure / timeout 3s)
  │   Stream Telecom
  ├── +375 (BY)   → SMSC.ru
  └── Other       → Twilio
          ↓ (failure / timeout 5s)
      Vonage
```

Circuit Breaker на каждом провайдере: открывается после 5 ошибок подряд, полуоткрытый режим через 60 секунд.

## Структура SMS-сообщения

### OTP-код

```text
Ваш код для входа в [Платформа]: 847391
Никому не сообщайте код.
Код действует 5 минут.
```

Параметры OTP:

- Длина: 6 цифр
- TTL: 5 минут
- Максимум попыток ввода: 5
- Блокировка повторной отправки: 60 секунд
- Максимум запросов за 24 часа: 10

### Критическое операционное SMS

```text
[Платформа] Груз #ORD-2025-004521:
Водитель прибыл на разгрузку.
Адрес: ул. Промышленная, 14
Позвонить водителю: +7 916 ***-**-12
```

### Аварийное уведомление

```text
[СРОЧНО] Рейс #SHP-2025-001234.
Водитель сообщает об аварии.
Координаты: 55.7558, 37.6173.
Свяжитесь с водителем или службой поддержки: 8-800-XXX-XX-XX
```

## Технические детали интеграции

### API-запрос к SMSC.ru

```http
POST https://smsc.ru/sys/send.php
Content-Type: application/x-www-form-urlencoded

login=api_login&psw=api_password&
phones=+79161234567&
mes=Ваш+код+847391&
charset=utf-8&
fmt=3&
id=notification_uuid
```

### Webhook-подтверждение доставки (Delivery Receipt)

```json
{
  "id": "notification_uuid",
  "phone": "+79161234567",
  "status": "DELIVERED",
  "delivered_at": "2025-03-15T14:31:05Z",
  "error_code": null
}
```

Статусы: `DELIVERED`, `UNDELIVERED` (номер недоступен), `NOT_FOUND` (неверный номер), `REJECTED` (заблокирован оператором).

## Управление согласиями (Opt-In / Opt-Out)

- **Opt-In**: явное согласие на получение SMS оформляется при регистрации. OTP-коды отправляются без согласия (законное основание — исполнение договора).
- **Opt-Out**: пользователь может отказаться от SMS в настройках профиля. При ответе «СТОП» на SMS — автоматическое отключение.
- Хранение согласий: таблица `sms_consent` с временными метками и источником согласия.

## Ограничения и лимиты

| Параметр                      | Значение                                     |
| ----------------------------- | -------------------------------------------- |
| Максимальная длина SMS        | 160 символов (GSM-7) / 70 символов (Unicode) |
| Многочастные SMS              | Автоматическая конкатенация (до 5 частей)    |
| Дневной лимит на пользователя | 10 SMS (кроме OTP)                           |
| Rate limit API провайдера     | 100 SMS/сек                                  |
| Стоимость за SMS (RU)         | ~2.5 руб./шт. (зависит от объёма)            |

## Мессенджер-шлюзы (Telegram, WhatsApp Business)

Для пользователей, у которых нет надёжного SMS-покрытия, предусмотрена отправка через мессенджеры как альтернативный канал:

| Мессенджер        | API               | Сценарий                         |
| ----------------- | ----------------- | -------------------------------- |
| Telegram Bot      | Bot API (Webhook) | Диспетчеры, опытные пользователи |
| WhatsApp Business | Cloud API (Meta)  | Международные клиенты            |

Активация мессенджер-канала — добровольная, через настройки профиля. При активации Telegram — пользователь проходит верификацию через Bot (`/start` → привязка аккаунта).
