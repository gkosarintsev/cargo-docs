# Маршрутизация для грузового транспорта (Truck Routing)

## Обзор

Построение маршрутов для грузовиков кардинально отличается от маршрутизации легковых автомобилей. Сервис маршрутизации (`Routing Engine`) должен учитывать массо-габаритные характеристики транспортного средства (ТС), дорожные знаки, ограничения и платные участки.

## Специфика грузовой маршрутизации

При запросе маршрута в Routing Engine всегда передается профиль грузовика. Учитываются следующие параметры и ограничения:

1. **Массо-габаритные ограничения (Weight & Dimensions)**:
   - **Масса**: Ограничения для грузовиков свыше 3.5т, 12т, 40т и т.д.
   - **Нагрузка на ось**: Критично для региональных дорог в период весенней просушки или для старых мостов.
   - **Габариты**: Высота (проезд под мостами, путепроводами, в туннелях), ширина, длина (ограничения на поворотах).
2. **Юридические и экологические запреты**:
   - Запрет на движение грузовиков в центре городов (например, ТТК, МКАД в Москве без пропусков).
   - Экологические зоны (Low Emission Zones - LEZ) в европейских городах (Euro 4, Euro 5, Euro 6).
   - Перевозка опасных грузов (ADR) — запрет на проезд через туннели и жилые зоны.
3. **Платные трассы и системы взимания платы**:
   - Учет зон действия системы «Платон» (РФ).
   - Платные дороги (Автодор, M-4, M-11, ЦКАД) — возможность построить альтернативный бесплатный маршрут для сравнения стоимости.

## Построение маршрута и провайдеры

Сервис маршрутизации использует внешние или self-hosted движки: **OSRM, Valhalla, Mapbox Navigation API, Yandex Routing API**.

### Формат запроса и ответа

- **Запрос**: Точки (Start, Waypoints, End), профиль ТС (высота=4m, масса=20t, оси=5), настройки избегания (avoid_tolls=false).
- **Ответ**:
  - **Геометрия маршрута (Geometry)**: Возвращается в виде закодированной полилинии (Encoded Polyline) или GeoJSON для отрисовки на карте в веб-интерфейсе или мобильном приложении.
  - **Пошаговые маневры (Turn-by-turn navigation)**: Инструкции для водителя ("через 300м поверните направо"), используемые в Driver App.
  - **Метаданные**: Общее расстояние, расчетное время в пути, пересекаемые платные дороги.

### Оптимизация

Для снижения затрат на платные API:

- Локальное развертывание **Valhalla** или **OSRM** с загруженными OSM графами (с тегами `maxweight`, `maxheight`) для 90% стандартных расчетов.
- Обращение к коммерческим API (Yandex/Mapbox) только для высокоточных маршрутов с учетом пробок или сложных городских зон.
