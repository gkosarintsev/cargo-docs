# Процесс архивации данных (Cold Storage)

## Архитектура
- Ежемесячные cron-джобы для архивации старых завершенных заказов и телеметрии.
- Данные экспортируются из PostgreSQL и TimescaleDB и конвертируются в колоночный формат **Apache Parquet**.
- Сохранение файлов в объектном хранилище **AWS S3 / MinIO**.

## Доступ к холодному архиву
- Аналитический холодный поиск по архиву осуществляется через **Presto / Trino / ClickHouse**.
- Позволяет строить тяжелую аналитику за длительные периоды без раздувания оперативной БД и без влияния на онлайн-нагрузки.
