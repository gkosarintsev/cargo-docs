# E2E Сценарии (End-to-End Testing)

Прогоняются с помощью **Playwright** (Веб-интерфейсы) и **Appium** (Мобильное приложение водителя).

## Ключевой золотой путь (Golden Path)
1. **Грузовладелец** публикует груз (Москва - СПб, 20т).
2. **Перевозчик** через поиск находит груз и подает оффер со своей ставкой.
3. **Грузовладелец** акцептует оффер -> Система формирует `TransportOrder`.
4. **Перевозчик** назначает машину и водителя.
5. **Водитель (Appium)** отмечает прибытие на загрузку, делает фото.
6. **Система** генерирует телеметрию (Mock GPS Ingestion).
7. **Водитель** прибывает на выгрузку, загружает фото накладной (PoD).
8. **Система** выставляет счет (Invoice).

Проверяются изменения статусов в реальном времени (WebSockets).
