# Нагрузочное тестирование

Для проверки отказоустойчивости применяется **k6** и **Gatling**.

## Ключевые сценарии нагрузки
1. **Stress Test поисковой подсистемы**: 1 500 RPS сложных гео-запросов (радиусные фильтры + фасеты) к OpenSearch API.
2. **High-Throughput GPS Ingestion**: Пиковая загрузка телематического шлюза (50 000 пакетов/сек от трекеров и мобильных устройств).
3. **Peak Day Marketplace**: Имитация активности 10 000 диспетчеров (создание грузов, одновременный торг, принятие офферов).

## Критерии успешности
- **Latency**: `p99 < 500ms` для критических API (поиск, прием GPS).
- **Error Rate**: Меньше `0.01%` при заявленной пиковой нагрузке.
