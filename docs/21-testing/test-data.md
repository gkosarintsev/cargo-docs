# Стратегия управления тестовыми данными

## 1. Синтетические генераторы (Fake Data Generators)
Созданы скрипты генерации правдоподобных логистических данных:
- Компании, ИНН, ОГРН (проходящие валидацию по контрольной сумме).
- Маршруты проложены по реальной дорожной сети (используя OSRM API).
- Синтетические GPS-треки, генерируемые по кривым Безье с учетом скоростных ограничений.

## 2. Обезличивание (Sanitization / Anonymization)
При выгрузке дампа БД с Production на Staging запускается pipeline обфускации:
- Имена, телефоны и email водителей/диспетчеров хэшируются или заменяются на моки.
- Реквизиты реальных банковских карт маскируются.
- Тексты сообщений в чатах заменяются на `Lorem Ipsum`.

## 3. Изоляция тестовых данных (Test Tenancy)
Для автоматических E2E тестов в Production создается отдельный `organization_id` (Тестовый Тенант), чьи данные отфильтровываются в BI-отчетах и не видны реальным участникам маркетплейса.
Автоматическая очистка тестовых сущностей выполняется ночным cron-джобом.
