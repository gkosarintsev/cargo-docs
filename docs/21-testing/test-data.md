# Стратегия управления тестовыми данными и Эталонные Seed-фикстуры (Test Data & Seeds)

## 1. Концепция и изоляция данных

Для запуска интеграционных тестов, локальной разработки (`docker compose up`) и CI/CD пайплайнов предоставляется детерминированный набор тестовых данных (**Golden Seed Dataset**).

- Все тестовые ИНН, ОГРН и КПП соответствуют государственным контрольным суммам РФ.
- Координаты геозон складов и точек погрузки соответствуют реальным логистическим паркам (Москва-Север, СПб-Шушары, Казань-РЦ).
- Изоляция данных: тестовые тенанты используют UUID с префиксом `00000000-0000-0000-0000-...` для автоматической фильтрации в BI-системах и аналитике.

---

## 4. Запуск Seed-данных в окружении разработки

```bash
# 1. Запуск БД и расширений в Docker
docker compose up -d postgres redis

# 2. Применение миграций Flyway / Goose
npm run db:migrate

# 3. Накатывание эталонных сид-данных
psql -h localhost -p 5432 -U postgres -d cargo_db -f docs/21-testing/test-data/seed.sql

# 4. Проверка готовности данных
psql -h localhost -p 5432 -U postgres -d cargo_db -c "SELECT count(*) FROM loads; SELECT count(*) FROM vehicles;"
```
