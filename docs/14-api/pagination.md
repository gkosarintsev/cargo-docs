# Пагинация и сортировка (Pagination)

> **Раздел:** 14-api  
> **Версия документа:** 1.0  
> **Статус:** Действующий стандарт  
> **Связанные документы:** [api-guidelines.md](api-guidelines.md)

---

## 1. Стратегии пагинации

Платформа поддерживает две стратегии пагинации в зависимости от типа данных:

| Стратегия        | Применение                                                              | Параметры                  |
| ---------------- | ----------------------------------------------------------------------- | -------------------------- |
| **Cursor-based** | Основная — для маркетплейса, живых лент, списков с частыми обновлениями | `limit`, `after`, `before` |
| **Offset-based** | Вспомогательная — только для статических справочников                   | `page`, `per_page`         |

---

## 2. Cursor-Based Pagination (основная)

### 2.1 Описание

Cursor-based пагинация решает ключевую проблему offset-пагинации — **пропуск или дублирование записей** при активной вставке новых данных (например, новые грузы появляются во время листания списка).

Курсор — это непрозрачный токен (opaque token), закодированный Base64, содержащий позицию относительно сортировки. Клиент не должен пытаться его декодировать или конструировать.

### 2.2 Параметры запроса

| Параметр | Тип     | Обязательный | Описание                                                        |
| -------- | ------- | :----------: | --------------------------------------------------------------- |
| `limit`  | integer |     Нет      | Количество записей на страницу. По умолчанию: 20. Максимум: 100 |
| `after`  | string  |     Нет      | Курсор — начало следующей страницы (пагинация вперёд)           |
| `before` | string  |     Нет      | Курсор — начало предыдущей страницы (пагинация назад)           |

> Параметры `after` и `before` **взаимоисключают** друг друга в одном запросе.

### 2.3 Примеры запросов

```http
# Первая страница
GET /api/v1/truck-offers?limit=50

# Следующая страница
GET /api/v1/truck-offers?limit=50&after=eyJpZCI6IjEyMyIsImNyZWF0ZWRfYXQiOiIyMDI0LTAzLTE1VDEwOjMwOjAwWiJ9

# Предыдущая страница
GET /api/v1/truck-offers?limit=50&before=eyJpZCI6IjQ1NiIsImNyZWF0ZWRfYXQiOiIyMDI0LTAzLTE1VDA5OjAwOjAwWiJ9
```

### 2.4 Структура ответа

```json
{
  "data": [
    {
      "id": "offer_abc123",
      "type": "truck_offer",
      "attributes": {
        "origin_city": "Москва",
        "destination_city": "Казань",
        "price_amount": 85000,
        "price_currency": "RUB",
        "available_from": "2024-03-16T08:00:00Z"
      }
    }
    // ... ещё 49 объектов
  ],
  "pagination": {
    "limit": 50,
    "next_cursor": "eyJpZCI6Ijk5OSIsImNyZWF0ZWRfYXQiOiIyMDI0LTAzLTE1VDA4OjAwOjAwWiJ9",
    "prev_cursor": "eyJpZCI6IjEiLCJjcmVhdGVkX2F0IjoiMjAyNC0wMy0xNVQxMjowMDowMFoifQ==",
    "has_more": true
  },
  "meta": {
    "total_count": 1248,
    "request_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
  }
}
```

**Описание полей `pagination`:**

| Поле          | Тип            | Описание                                                               |
| ------------- | -------------- | ---------------------------------------------------------------------- |
| `limit`       | integer        | Запрошенный размер страницы                                            |
| `next_cursor` | string \| null | Курсор для получения следующей страницы. `null` — страниц больше нет   |
| `prev_cursor` | string \| null | Курсор для получения предыдущей страницы. `null` — это первая страница |
| `has_more`    | boolean        | `true` если существует следующая страница                              |

### 2.5 Поведение на первой и последней странице

```
// Первая страница:
"prev_cursor": null  // Нет предыдущей страницы

// Последняя страница:
"next_cursor": null,
"has_more": false
```

## 3. Offset-Based Pagination (для справочников)

### 3.1 Ограничения применения

Offset-пагинация **допустима только** для следующих ресурсов:

- Справочник городов (`/api/v1/cities`)
- Справочник типов грузов (`/api/v1/cargo-types`)
- Справочник валют (`/api/v1/currencies`)
- Прочие статические справочники

**Запрещено** использовать offset-пагинацию для:

- Списков грузов и предложений
- Транспортных заказов
- Любых ресурсов с частыми обновлениями

### 3.2 Параметры запроса

| Параметр   | Тип     | По умолчанию | Максимум |
| ---------- | ------- | :----------: | :------: |
| `page`     | integer |      1       |    —     |
| `per_page` | integer |      20      |   100    |

```http
GET /api/v1/cargo-types?page=2&per_page=20
```

### 3.3 Структура ответа

```json
{
  "data": [ ... ],
  "pagination": {
    "page": 2,
    "per_page": 20,
    "total_pages": 5,
    "total_count": 98
  },
  "meta": {
    "request_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
  }
}
```

## 4. Сортировка

### 4.1 Синтаксис параметра `sort`

```
sort=[-]field1[,[-]field2,...]
```

- `-` (минус) перед именем поля — сортировка по убыванию (DESC).
- Без минуса — сортировка по возрастанию (ASC).
- Несколько полей разделяются запятой (составная сортировка).

### 4.2 Примеры

```http
# По убыванию даты создания (новые первыми)
GET /api/v1/loads?sort=-created_at

# Сначала дешевле, потом по дате создания
GET /api/v1/truck-offers?sort=price_amount,-created_at

# Множественная сортировка
GET /api/v1/loads?sort=-weight_kg,origin_city
```

### 4.3 Доступные поля сортировки по ресурсам

**Грузы (`/loads`):**

| Поле             | Описание                   |
| ---------------- | -------------------------- |
| `created_at`     | Дата создания объявления   |
| `price_amount`   | Стоимость перевозки        |
| `weight_kg`      | Вес груза                  |
| `available_from` | Дата готовности к отправке |
| `distance_km`    | Расстояние маршрута        |

**Предложения перевозчиков (`/truck-offers`):**

| Поле             | Описание                  |
| ---------------- | ------------------------- |
| `created_at`     | Дата создания предложения |
| `price_amount`   | Ставка перевозчика        |
| `available_from` | Доступность транспорта    |
| `carrier_rating` | Рейтинг перевозчика       |

### 4.4 Ошибка неверного поля сортировки

```json
// 400 Bad Request
{
  "type": "https://api.cargo.platform/errors/invalid-sort-field",
  "title": "Недопустимое поле сортировки",
  "status": 400,
  "detail": "Поле 'unknown_field' не поддерживается для сортировки",
  "error_code": "INVALID_SORT_FIELD",
  "allowed_fields": [
    "created_at",
    "price_amount",
    "weight_kg",
    "available_from"
  ]
}
```

## 5. Комбинирование пагинации, сортировки и фильтрации

```http
# Cursor-based + сортировка + фильтры
GET /api/v1/loads?limit=50&after=<cursor>&sort=-created_at&origin_city=Москва&min_weight_kg=1000

# Offset + сортировка для справочника
GET /api/v1/cargo-types?page=1&per_page=50&sort=name
```

> **Важно:** При cursor-based пагинации сортировка должна быть **согласована** между страницами. Изменение параметра `sort` при переходе на следующую страницу с помощью курсора приведёт к ошибке `400 Bad Request`.
