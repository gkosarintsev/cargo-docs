# Модель ценообразования перевозки

## Структура цены

Цена перевозки формируется из базовой ставки и различных доплат, а также может корректироваться за счет штрафов и удержаний:

- **Базовая ставка**: Может рассчитываться тремя способами:
  - Фиксированная сумма за рейс (Fixed)
  - Ставка за километр (Per Km)
  - Ставка за час работы (Per Hour)
- **Доплаты**: Применяются за специфические условия и услуги:
  - Дополнительные точки маршрута
  - Растентовка (боковая, верхняя погрузка)
  - Использование гидроборта
  - Соблюдение температурного режима (рефрижератор)
  - Перевозка опасных грузов (ADR)
  - Наличие спецпропуска (например, для въезда в центр города)
- **Сверхнормативный простой (Demurrage)**: Оплата дополнительного времени ожидания на погрузке/выгрузке сверх установленного норматива.
- **Штрафы и удержания**: Снижение стоимости за опоздания, порчу груза или нарушение условий договора.

## Налоговая модель

Система поддерживает различные режимы налогообложения для корректных расчетов между контрагентами:

- **С НДС (20%)**: Стандартная модель для плательщиков НДС.
- **Без НДС (УСН)**: Для организаций, применяющих упрощенную систему налогообложения.
- **Смешанные расчеты**: Автоматический расчет НДС-надбавки при взаимодействии участников с разными налоговыми режимами.

## Мультивалютность

Платформа поддерживает работу с несколькими базовыми валютами для международных перевозок:

- RUB (Российский рубль)
- KZT (Казахстанский тенге)
- BYN (Белорусский рубль)
- USD (Доллар США)
- EUR (Евро)

**Фиксация курса**: Конвертация и фиксация стоимости производится по официальному курсу ЦБ на дату заключения сделки.
