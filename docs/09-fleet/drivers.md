# Водительский состав (Drivers)

## Обзор

Модуль управления водительским составом отвечает за профили водителей, контроль их допусков, документов и текущего рабочего статуса.

## Модель сущности `Driver`

Основная информация о водителе:

- **ФИО**: Полное имя водителя.
- **Телефон для связи**: Основной контактный номер.
- **Водительское удостоверение (ВУ)**: Номер ВУ, дата выдачи и срок действия.
- **Категории**: Разрешенные категории вождения (особое внимание на C и CE).
- **Стаж работы**: Общий водительский стаж.
- **Карта водителя для цифрового тахографа**: Номер и срок действия карты (блок СКЗИ для РФ или ЕСТР для международных рейсов).

## Спецдопуски и сертификаты

Для выполнения специализированных рейсов фиксируются дополнительные документы:

- **Свидетельство ДОПОГ (ADR)**: Допуск к перевозке опасных грузов (с указанием классов опасности).
- **Санитарная книжка**: Необходима для перевозки пищевых продуктов.
- **Загранпаспорт и визы**: Данные документов, необходимых для выполнения международных перевозок.

## Интеграция с мобильным приложением

Каждый профиль водителя связан с учетной записью в системе:

- **UserId**: Идентификатор пользователя для авторизации в мобильном приложении водителя. Это позволяет отправлять маршрутные задания, принимать статусы рейсов и электронные документы.

## Статусы водителя

Жизненный цикл и текущее состояние водителя:

- `AVAILABLE`: Готов к назначению на рейс.
- `ON_DUTY`: Находится на смене (выполняет рейс или другие рабочие обязанности).
- `IN_REST_PERIOD`: Находится на межсменном или еженедельном отдыхе (в соответствии с нормами РТО).
- `SICK_LEAVE`: Находится на больничном.
- `BLOCKED`: Отстранен от работы (например, из-за просроченных документов или нарушений).
