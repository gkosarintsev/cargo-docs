# Интеграция с банками и платежными провайдерами

## Подключение эквайринга
- Интеграция с интернет-эквайрингом (Тинькофф, Сбербанк, Точка).
- Поддержка номинальных счетами Escrow для безопасных сделок.
- B2B СБП для быстрых расчетов.

## Обработка платежных вебхуков
- Верификация подписи вебхука от банка (HMAC).
- Сверка реестров выплат.
- Автоматическая выплата на расчетные счета перевозчиков.
