# Интеграция с учетными системами ERP

## Синхронизация мастер-данных
- Автоматическая загрузка контрагентов, договоров, подразделений из 1C:ERP, SAP S/4HANA, Oracle в платформу.
- Маппинг ID контрагентов и расчетных счетов.

## Автоматическая передача закрывающих бухгалтерских документов
- УПД, счета, акты передаются по факту подтверждения доставки (статус `DELIVERED` в платформе).
- Автоматическое формирование и передача черновиков в ERP.

## Сверка взаиморасчетов и передача статусов оплат счетов
- Синхронизация статусов счетов (`PAID`, `PARTIALLY_PAID`).
- Передача банковских выписок.
