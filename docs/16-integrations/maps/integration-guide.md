# Картография, Геокодинг и Маршрутизация

## Адаптеры к внешним картографическим сервисам
- Поддержка OpenStreetMap/OSRM для бесплатных маршрутов.
- Интеграция Yandex Maps API для РФ.
- DaData для нормализации и геокодирования адресов.
- 2ГИС для детализированных маршрутов по городу.

## Стратегии оптимизации
- Кэширование запросов геокодинга (Redis).
- Расчет матрицы расстояний для пакетной оптимизации.
- Fallback-стратегия: переключение с Яндекс.Карт на OSRM при превышении квот API.
