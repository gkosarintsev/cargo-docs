# Интеграция со складскими системами WMS

## Управление временными окнами (Yard Management)
- Бронирование тайм-слотов (Time Slot Management) погрузки/выгрузки.
- Оптимизация пропускной способности рампы.

## Оповещение склада о расчетном времени прибытия (ETA)
- Уведомление ETA Notification за 1 час до прибытия фуры на основе телеметрии платформы.

## Фиксация времени
- Фактическое время заезда на склад (по геозоне или шлагбауму).
- Постановка к рампе.
- Окончание погрузочных работ.

## Передача упаковочных листов
- Обмен документами и фиксация расхождений по номенклатуре.
