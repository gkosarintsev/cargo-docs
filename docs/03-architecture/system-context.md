# Системный контекст (System Context)

## Описание границ системы (System Boundary)

Цифровая логистическая платформа представляет собой комплексное программное решение, обеспечивающее взаимодействие участников рынка грузоперевозок. Платформа автоматизирует процессы поиска грузов и транспорта (Marketplace), управления исполнением перевозок (Transport Execution), а также отслеживания местоположения транспортных средств в реальном времени (Tracking). В границы системы входят основные веб-интерфейсы, мобильное приложение для водителей, а также бэкенд-сервисы и хранилища данных. Все внешние системы и интеграции находятся за границами платформы.

## Внешние пользователи

- **Грузовладельцы / Экспедиторы**: Публикация грузов, поиск перевозчиков, проведение тендеров, отслеживание доставки. Доступ через Web SPA.
- **Перевозчики / Диспетчеры**: Поиск грузов, предоставление транспорта, управление автопарком, мониторинг рейсов. Доступ через Web SPA.
- **Водители**: Получение маршрутных заданий, отметка статусов в пути, обмен документами. Доступ через Mobile Android/iOS App.
- **Администраторы и служба поддержки платформы**: Управление пользователями, модерация, биллинг, мониторинг системы. Доступ через Web Admin Portal.

## Внешние системы

- **Внешние TMS / ERP / WMS клиентов**: Интеграция с корпоративными системами грузовладельцев и перевозчиков для автоматического обмена заявками и статусами (REST / Webhooks).
- **Телематические шлюзы и GPS-трекеры**: Получение геоданных от транспортных средств (Wialon, Omnicomm, Galileosky, HTTP/MQTT шлюзы).
- **Картографические и геокодинговые сервисы**: Построение маршрутов, расчет ETA, геокодирование адресов (OpenStreetMap/OSRM, Yandex Maps, HERE).
- **Платёжные шлюзы и эквайринг**: Проведение транзакций, оплата подписок, B2B-переводы (Банковский эквайринг, СБП, Счета/B2B-платежи).
- **Операторы ЭДО / ГИС ЭПД**: Юридически значимый документооборот, электронные транспортные накладные (eCMR).
- **Сервисы скоринга и проверки контрагентов**: Проверка благонадежности компаний, антифрод (ФНС, Контур.Фокус, DaData).
- **Шлюзы коммуникаций**: Отправка уведомлений пользователям (SMS, Push FCM/APNs, Email SMTP/SendGrid).
