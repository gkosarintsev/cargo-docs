# Справочник и семантика статусов (Shipment Statuses)

Данный документ описывает жизненный цикл рейса (`Shipment`) с точки зрения его статусной модели. Статусы обеспечивают прозрачность выполнения перевозки для всех участников процесса.

## 1. Полная иерархия статусов исполнения перевозки

Жизненный цикл стандартного рейса представляет собой следующий линейный переход состояний:

1. `ASSIGNED` (Ресурсы назначены)
2. `CONFIRMED_BY_DRIVER` (Рейс подтвержден водителем)
3. `EN_ROUTE_TO_PICKUP` (В пути на погрузку)
4. `AT_PICKUP` (Прибыл на погрузку)
5. `LOADING` (Идет погрузка)
6. `LOADED` (Погрузка завершена)
7. `IN_TRANSIT` (В пути на выгрузку)
8. `AT_DELIVERY` (Прибыл на выгрузку)
9. `UNLOADING` (Идет выгрузка)
10. `DELIVERED` (Груз доставлен)
11. `DOCUMENTS_APPROVED` (Документы проверены)
12. `COMPLETED` (Рейс завершен)

_Примечание: При мультистопах (несколько точек погрузки/выгрузки) статусы с 3 по 9 могут повторяться (циклично) для каждой точки маршрута._

## 2. Таблица атрибутов каждого статуса

В таблице ниже описаны условия перехода в каждый статус, необходимые данные и генерируемые события.

| Статус                    | Кто инициирует                              | Обязательные данные при смене                       | События и уведомления                                |
| :------------------------ | :------------------------------------------ | :-------------------------------------------------- | :--------------------------------------------------- |
| **`ASSIGNED`**            | Диспетчер Перевозчика (через TMS)           | `VehicleId`, `DriverId`                             | Push водителю. Событие `ShipmentAssigned`            |
| **`CONFIRMED_BY_DRIVER`** | Водитель (вручную в приложении)             | Отметка времени (Timestamp)                         | Обновление TMS диспетчера                            |
| **`EN_ROUTE_TO_PICKUP`**  | Водитель (вручную)                          | Timestamp, Гео-координаты (начало трекинга)         | Уведомление Грузоотправителю                         |
| **`AT_PICKUP`**           | Геозона (автоматически) / Водитель (резерв) | Timestamp, Гео-координаты (внутри полигона точки)   | SMS/Email Заказчику, Смена статуса на табло склада   |
| **`LOADING`**             | Склад / Водитель                            | Timestamp                                           | -                                                    |
| **`LOADED`**              | Водитель (вручную)                          | Timestamp, Фото закрепленного груза (опц.), Одометр | Событие `ShipmentLoaded`, Webhook Заказчику          |
| **`IN_TRANSIT`**          | Система (сразу после `LOADED`)              | Гео-координаты                                      | Отслеживание трекинга (ETAs updates)                 |
| **`AT_DELIVERY`**         | Геозона (автоматически) / Водитель (резерв) | Timestamp, Гео-координаты                           | Уведомление Грузополучателю о прибытии машины        |
| **`UNLOADING`**           | Склад / Водитель                            | Timestamp                                           | -                                                    |
| **`DELIVERED`**           | Водитель (вручную)                          | Timestamp, Фото выгруженного груза, Данные PoD      | Событие `ShipmentDelivered`, Webhook/SMS Заказчику   |
| **`DOCUMENTS_APPROVED`**  | Модератор Платформы / Заказчик              | Идентификаторы проверенных документов               | Разблокировка оплаты                                 |
| **`COMPLETED`**           | Система (автоматически)                     | -                                                   | Рейс переходит в архив, формирование финального акта |
