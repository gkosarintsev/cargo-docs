# Изоляция тенантов (Tenant Isolation)

- **API Gateway**: Проверка токена и внедрение заголовка `X-Organization-ID` для маршрутизации внутри микросервисов.
- **Service Layer**: Каждый микросервис обязан проверять принадлежность запрашиваемого ресурса к `organization_id` из контекста запроса.
- **Database (RLS)**: В PostgreSQL включена технология Row Level Security (RLS). Каждая транзакция устанавливает переменную сессии `SET LOCAL tenant.organization_id = 'xxx'`, что гарантирует изоляцию на уровне движка СУБД.
- **Message Broker**: Топики Kafka разделяются партициями, а консьюмеры проверяют заголовок `tenant_id` перед обработкой сообщения.
