# Аутентификация

- **Политика паролей**: Хеширование с использованием Argon2id. Минимальная длина пароля — 12 символов. Автоматическая проверка по базам HIBP (скомпрометированные пароли).
- **Жизненный цикл сессий**: JWT Access-токены (срок 15 минут) + Opaque Refresh-токены (срок 14 дней с ротацией).
- **Защита от CSRF**: Использование флагов `Secure`, `HttpOnly` и `SameSite=Strict` для всех cookies.
- **Мобильное приложение**: Безопасное хранение токенов в защищенных анклавах (Android Keystore / iOS Keychain).
- **SSO / SAML**: Поддержка аутентификации через корпоративные системы (Active Directory / Keycloak) для крупных заказчиков.
