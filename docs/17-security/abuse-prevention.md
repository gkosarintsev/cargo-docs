# Предотвращение злоупотреблений и фрода

- **Fraud Monitoring Engine (Антифрод)**: Система мониторинга поведенческих аномалий в реальном времени.
  - Алерты: массовое создание грузов (например, 50 за 1 минуту), вход под одним аккаунтом из разных стран одновременно, частая смена банковских реквизитов перед оплатой.
  - Действия: Временная блокировка аккаунта (Quarantine), требование повторной верификации через СМС/Лицо, оповещение службы безопасности.
- **CAPTCHA**: Обязательное использование Cloudflare Turnstile или reCAPTCHA v3 (невидимая капча) на формах регистрации, авторизации и восстановления пароля.
