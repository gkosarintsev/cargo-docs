# Модель угроз (Threat Model / STRIDE)

В этом документе проведен глубокий анализ угроз безопасности логистической B2B платформы и специфицированы превентивные/компенсационные меры защиты.

## 1. Account Takeover (Захват аккаунта диспетчера/руководителя)
- **Вектор**: Фишинг, перебор паролей (brute force), утечка сессионных токенов через XSS, кража устройства.
- **Защита**: Обязательная 2FA (TOTP или SMS) для чувствительных действий (финансовые операции, выгрузка базы), детекция входа с аномальных IP/устройств (Impossible Travel Alert), строгая ротация Refresh-токенов при каждом использовании (Token Rotation), принудительный отзыв всех сессий при смене пароля.

## 2. Fake Companies & Fake Loads / Carriers (Фиктивные фирмы и грузы-приманки)
- **Вектор**: Регистрация по поддельным документам для перехвата грузов (Freight Theft), публикации фейковых ставок.
- **Защита**: Многоуровневая верификация (KYC/KYB), автоматическая проверка ЕГРЮЛ через API ФНС, видео-верификация директоров (Liveness check), проверка реального автопарка по базам ГИБДД, система антифрода, карантин новых аккаунтов.

## 3. Marketplace Scraping & Price Manipulation (Скрапинг и манипуляция)
- **Вектор**: Бот-фермы и автоматизированные скрипты скрапят доски грузов для конкурентной разведки или демпинга.
- **Защита**: Cloudflare Bot Management (WAF), динамический Rate Limiting по IP/пользователю, подгрузка контактов диспетчера только по клику с жестким суточным лимитом на аккаунт.

## 4. Tenant Isolation Breach / BOLA / IDOR (Утечка чужих данных)
- **Вектор**: Подмена `organization_id` или `load_id` в REST-запросах для доступа к чужим ставкам и контрактам.
- **Защита**: Автоматизированная проверка владения объектом в API Gateway / Middleware, внедрение Row Level Security (RLS) в PostgreSQL, запрет использования инкрементальных ID (переход на UUIDv4).

## 5. Malicious File Upload (Вредоносные вложения)
- **Вектор**: Загрузка вирусов, троянов или макросов под видом PDF/JPEG накладных, сканов договоров или фото PoD.
- **Защита**: Проверка загружаемых файлов антивирусом (ClamAV) в отдельном serverless/S3 пайплайне, строгая валидация MIME-типов по магическим байтам (сигнатурам файлов), а не по расширениям, переименование файлов при сохранении.

## 6. Webhook Forgery & Replay Attacks (Подделка вебхуков)
- **Вектор**: Отправка фальшивых статусов доставки (перехват управления рейсом) от лица телематических провайдеров.
- **Защита**: Валидация HMAC-SHA256 подписи в заголовках (`X-Cargo-Signature`), проверка timestamp для защиты от повторов (Time Window < 5 минут), поддержка пула доверенных IP-адресов.
