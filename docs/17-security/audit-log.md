# Неизменяемый журнал аудита (Audit Trail)

Система обязана вести защищенный лог критических действий для расследований инцидентов.

## Критические действия
- Изменение банковских реквизитов организации.
- Назначение, изменение прав или удаление пользователей.
- Выгрузка (экспорт) списков клиентов/грузов.
- Смена водителя или транспортного средства в активном рейсе.
- Отмена подписанного договора-заявки.

## Структура записи аудита
- `timestamp`: точное время по UTC.
- `actor_id` / `actor_org_id`: инициатор действия.
- `ip_address`: IP и User-Agent.
- `action`: уникальный идентификатор действия (например, `UPDATE_BANK_ACCOUNT`).
- `resource_type` / `resource_id`: затронутый объект.
- `diff_before_after`: JSON с изменениями (до/после).

## Защита от модификации
Логи пишутся в **Append-only storage** (WORM — Write Once Read Many), например, в AWS QLDB или отдельный защищенный кластер ElasticSearch без права на UPDATE/DELETE, даже для администраторов БД.
