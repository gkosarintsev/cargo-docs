# Шифрование данных

- **Data-at-Rest (Данные в покое)**: 
  - LUKS-шифрование дисков на уровне виртуальных машин.
  - AES-256 шифрование бакетов S3 (SSE-S3 или SSE-KMS) для сканов документов и резервных копий БД.
- **Data-in-Transit (Данные в пути)**: 
  - Обязательное использование **TLS 1.3** для внешнего веб-трафика с принудительным HSTS (HTTP Strict Transport Security).
  - Внутренний кластерный трафик защищается через **mTLS** (Mutual TLS) с использованием Service Mesh (Istio или Linkerd).
