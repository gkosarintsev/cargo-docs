# Управление секретами и ключами

- **Хранилище секретов**: Все системные пароли, токены API и ключи шифрования хранятся в **HashiCorp Vault** (или AWS Secrets Manager). Запрет на хранение секретов в git-репозиториях.
- **Доступ микросервисов**: Приложения получают секреты при старте через Kubernetes Secrets (External Secrets Operator).
- **Ротация ключей**:
  - API-ключи сторонних интеграций ротируются автоматически раз в 90 дней.
  - Сертификаты TLS обновляются автоматически через Cert-Manager и Let's Encrypt.
