# Спецификация сред (Environments)

## 1. Development (Dev)
- **Назначение**: Разработка, интеграция веток, нестабильная среда.
- **Изоляция**: Отдельный namespace в кластере Dev, уменьшенные лимиты CPU/RAM.

## 2. Staging
- **Назначение**: Предрелизное тестирование QA инженерами и автоматизированные E2E тесты.
- **Изоляция**: Отдельный VPC / кластер. Копия Prod конфигурации и анонимизированный дамп БД.

## 3. Production (Prod)
- **Назначение**: Обслуживание реальных пользователей.
- **Изоляция**: Изолированный VPC без прямого доступа из офисной сети (только через VPN/Bastion и MFA). Строгие квоты ресурсов, Network Policies по умолчанию запрещают все подключения.
