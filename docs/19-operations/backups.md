# Регламент резервного копирования

## Стратегия Бэкапов
- **PostgreSQL**:
  - Непрерывное WAL-G архивирование в S3 (Point-In-Time Recovery).
  - Ежедневный полный снэпшот БД (LVM/EBS) ночью (02:00 UTC).
- **OpenSearch**: Ежедневные снэпшоты индексов (Snapshot API) в S3 бакет.
- **S3 Object Storage**: Включено Cross-Region Versioning и Replication для защиты от случайного удаления файлов (например, PoD-документов).

## Учения по восстановлению (Disaster Recovery Drills)
- Регулярные учения проводятся **раз в квартал**.
- SRE команда разворачивает кластер из бэкапа в изолированном VPC и валидирует целостность данных за последние 24 часа.
