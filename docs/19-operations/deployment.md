# Управление конфигурациями и развертыванием

## GitOps Подход
- **Инструменты**: Развертывание Kubernetes манифестов осуществляется по модели GitOps с использованием **ArgoCD** (или Flux).
- Вся инфраструктура и конфигурация описана декларативно в отдельном репозитории `infrastructure-manifests`.
- Запрещено ручное применение манифестов (`kubectl apply`) в Production.

## Стратегии релиза
- **Canary Deployment**: Постепенный раскат новой версии микросервиса на 5%, 10%, 25%, 50%, 100% трафика с автоматическим откатом при росте Error Rate (через Argo Rollouts).
- **Blue/Green Deployment**: Для критичных компонентов БД с миграциями.
