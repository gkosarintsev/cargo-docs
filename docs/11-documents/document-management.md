# Архитектура управления документами

Система документооборота строго разделяет хранение метаданных и самих бинарных файлов (сканов, PDF, XML и т.д.), обеспечивая высокую производительность, безопасность и соответствие требованиям.

## Разделение хранения

### Метаданные (PostgreSQL)

Метаданные документов хранятся в реляционной базе данных (PostgreSQL) для обеспечения транзакционности, быстрого поиска и связи с основными сущностями домена.

Основные поля метаданных:

- `document_id`: Уникальный идентификатор документа (UUID).
- `entity_type`: Тип сущности, к которой привязан документ (`Order`, `Shipment`, `Organization`).
- `doc_type`: Тип документа (например, `CMR`, `WAYBILL`, `INVOICE`).
- `version`: Текущая версия документа.
- `mime_type`: Тип содержимого файла (MIME type).
- `file_size`: Размер файла в байтах.
- `sha256_hash`: Хэш-сумма файла для контроля целостности.
- `s3_key`: Уникальный ключ объекта в хранилище S3.
- `created_by`: Идентификатор пользователя/системы, загрузившего документ.
- `status`: Статус документа в его жизненном цикле (например, `GENERATED`, `SIGNED`).

### Файлы (S3 Object Storage)

Бинарные файлы хранятся в объектном хранилище (S3), что обеспечивает масштабируемость и экономичность:

- **Неизменяемое хранение (WORM - Write Once, Read Many)**: Файлы после загрузки не могут быть изменены. Любая правка приводит к созданию новой версии.
- **Шифрование на стороне сервера (SSE-S3)**: Все данные шифруются прозрачно для приложения.
- **Безопасный доступ**: Файлы не публикуются в открытом виде. Для скачивания или просмотра приложения генерируют безопасные короткоживущие Pre-signed URLs.

## Пакет документов (DocumentPackage)

Для упрощения обмена документами (например, при отправке закрывающих документов клиенту) используется механизм пакетирования:

- **Объединение**: Все документы, относящиеся к конкретной перевозке (Shipment/Order), собираются в единый ZIP-архив.
- **Проверка комплектности**: Перед генерацией пакета система может автоматически проверять наличие обязательных документов согласно условиям договора (например, ТТН + УПД + Договор-заявка).
