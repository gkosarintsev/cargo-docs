# Политика архивного хранения и уничтожения (Retention Policy)

Управление жизненным циклом данных включает не только хранение, но и своевременное и безопасное удаление информации для оптимизации расходов на инфраструктуру и соблюдения правовых норм.

## Сроки хранения

Сроки хранения документов строго регламентируются законодательством:

- **5 лет**: Первичные бухгалтерские документы (УПД, счета-фактуры) — хранение по налоговым требованиям.
- **3 года**: Договоры, заявки и общая коммерческая переписка — срок исковой давности по гражданским делам.
- **1 год**: Сырые подтверждающие файлы (фотографии PoD низкого разрешения, промежуточные статусы) — оперативные данные, не требующие длительного хранения.

## Автоматическая ротация и S3 Lifecycle Rules

Для оптимизации стоимости хранения в S3 используются правила жизненного цикла:

1.  **Горячее хранение (Standard)**: Документы в активной фазе (до подписания + 30 дней после).
2.  **Теплое хранение (Infrequent Access)**: Документы за последние 1-2 года. Менее частый доступ, сниженная стоимость.
3.  **Холодный архив (Glacier / Deep Archive)**: Документы старше 2 лет. Доступ предоставляется с задержкой, стоимость хранения минимальна.

Автоматическая ротация по этим уровням настроена через политики S3 (Lifecycle Configuration).

## Гарантированное удаление (Right to be Forgotten)

В соответствии с требованиями законодательства о защите персональных данных (GDPR / 152-ФЗ), система поддерживает регламент гарантированного удаления:

- **Обезличивание**: По запросу субъекта персональные данные (например, ФИО или телефон конкретного водителя-ИП) могут быть обезличены в системе.
- **Целостность архива**: Удаление или обезличивание выполняется таким образом, чтобы не нарушать целостность бухгалтерского архива. Финансовые и налоговые документы остаются в неизменном виде в течение обязательного срока хранения (5 лет), так как налоговые требования превалируют над правом на забвение. Удаление происходит только по истечении установленных сроков хранения (Hard Delete).
