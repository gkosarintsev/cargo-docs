# Электронная подпись

## Обзор

Система использует три вида электронных подписей в соответствии с Федеральным законом № 63-ФЗ «Об электронной подписи». Выбор вида подписи определяется юридической значимостью и оперативностью операции.

## Виды электронных подписей

### ПЭП — Простая электронная подпись

**Область применения**: оперативные отметки водителя в мобильном приложении, подтверждение прибытия на точку, фотофиксация PoD.

**Реализация**:

- SMS-код, отправляемый на зарегистрированный номер телефона водителя.
- Push-подтверждение в мобильном приложении водителя (in-app approval).

**Юридическая сила**: признаётся при наличии соответствующего соглашения между сторонами. Не применяется для государственно-значимых документов (ЭТрН, счета-фактуры).

---

### УНЭП — Усиленная неквалифицированная электронная подпись

**Область применения**: согласование договоров-заявок внутри платформы, внутренние акты и согласования.

**Реализация**:

- Сертификат, выпущенный удостоверяющим центром платформы (не аккредитованным ФСБ).
- Хранение закрытого ключа в защищённом хранилище пользователя (браузерный криптопровайдер или облачный HSM платформы).

**Юридическая сила**: признаётся между сторонами в рамках соглашения об использовании УНЭП. Не принимается государственными органами в качестве равнозначной собственноручной подписи.

---

### УКЭП — Усиленная квалифицированная электронная подпись

**Область применения**: подписание титулов ЭТрН, eCMR, счетов-фактур, УПД — всех документов с юридической силой, признаваемой государством.

**Реализация**:

| Способ               | Описание                                           | Применение                        |
| -------------------- | -------------------------------------------------- | --------------------------------- |
| **КриптоПро CSP**    | Локальный криптопровайдер на ПК                    | Диспетчеры и бухгалтеры в офисе   |
| **Рутокен / eToken** | Аппаратный USB-токен с защищённым хранилищем ключа | Руководители, главные бухгалтеры  |
| **Облачная КЭП**     | Ключ хранится в аккредитованном облачном УЦ        | Водители и мобильные пользователи |

**Юридическая сила**: полностью равнозначна собственноручной подписи для любых документов в соответствии с 63-ФЗ. Обязательна для работы с ГИС ЭПД.

## Валидация подписи

При проверке подписи система выполняет следующие шаги:

```
1. Проверка формата подписи (CAdES, XAdES, PAdES)
2. Проверка цепочки сертификатов до корневого УЦ
3. Проверка статуса сертификата (OCSP / CRL)
4. Проверка метки точного времени (TSP — Time Stamp Protocol)
5. Проверка целостности подписанных данных (хэш)
```

### Форматы и стандарты

- **CAdES-BES**: базовая подпись с сертификатом (для простых случаев).
- **CAdES-T**: подпись с меткой времени (TSP) — защита от отказа от подписи.
- **CAdES-X Long**: расширенная долгосрочная подпись — включает доказательства валидности сертификата на момент подписания. **Используется для ЭТрН и eCMR**, обеспечивает верификацию даже после истечения срока сертификата.

### Метки точного времени (TSP)

Метки времени запрашиваются у аккредитованных служб TSA (Time Stamp Authority):

- ПАО «КриптоПро» TSA
- АО «Аладдин Р.Д.» TSA

Метка фиксирует, что подпись была наложена в конкретный момент времени, что критически важно для долгосрочного хранения документов.

## Хранение информации о подписях

В PostgreSQL в таблице `document_signatures` хранится:

| Поле                 | Описание                                  |
| -------------------- | ----------------------------------------- |
| `signature_id`       | UUID                                      |
| `document_id`        | Ссылка на документ                        |
| `signer_id`          | Ссылка на пользователя                    |
| `signature_type`     | ПЭП / УНЭП / УКЭП                         |
| `certificate_serial` | Серийный номер сертификата                |
| `signed_at`          | Время подписания (из TSP-метки)           |
| `signature_data`     | Данные подписи (CAdES-контейнер) в Base64 |
| `validation_status`  | Статус последней проверки                 |
| `validated_at`       | Время последней проверки                  |
