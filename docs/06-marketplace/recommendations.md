# Система рекомендаций

Система рекомендаций направлена на проактивное вовлечение пользователей и повышение ликвидности платформы за счет умных подсказок и уведомлений.

## 1. Персональные рассылки для перевозчиков

Вместо того чтобы ждать, пока перевозчик сам зайдет в поиск, система проактивно предлагает релевантные варианты.

- **Триггеры «Вам подходит груз»**: Push-уведомления и Email-рассылки, срабатывающие при появлении в системе нового высоколиквидного груза.
- **Основа для рекомендаций**:
  - **Saved Searches (Сохраненные фильтры)**: Явные предпочтения, заданные перевозчиком.
  - **Frequent Lanes (Частые маршруты)**: Неявные предпочтения, выявляемые ML-моделью на основе истории успешных рейсов перевозчика. Если автопарк регулярно возит по маршруту "Москва - Казань", при появлении "горящего" груза по хорошей ставке на этом направлении, система уведомит его в первую очередь.

## 2. Умные подсказки для грузовладельцев (Price Guidance)

Для ускорения контрактации и снижения процента невывезенных грузов, система помогает грузовладельцам устанавливать адекватную рыночную цену.

- **Аналитика рыночной ставки**: В момент создания или редактирования груза, система анализирует аналогичные завершенные сделки (по маршруту, типу кузова, весу) за последние N дней.
- **Рекомендательный виджет**: В интерфейсе отображается подсказка: _«Рекомендуемая рыночная ставка для быстрой контрактации: 120 000 руб.»_
- **Динамическое ценообразование (Smart Pricing)**: Опциональная возможность для грузовладельца включить автоматическое повышение ставки (с заданным шагом и до заданного максимума), если груз не забирают в течение длительного времени, приближаясь к дедлайну погрузки.
