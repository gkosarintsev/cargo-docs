# Биржевые аукционные механики и алгоритмы торгов (Auction Mechanisms)

## 1. Концепция биржевых торгов фрахтом

Биржа платформы поддерживает 4 специализированных типа аукционных механик для спотового и контрактного рынка автомобильных грузоперевозок (FTL):

```mermaid
graph TD
    A[Публикация груза грузовладельцем] --> B{Выбор типа торгов}
    B -->|Снижение цены открытыми ставками| C[1. Reverse English Auction]
    B -->|Горящий рейс / Срочная подача| D[2. Dutch Auction на повышение]
    B -->|Регулярный корпоративный пул| E[3. Sealed-bid Tender]
    B -->|Фиксированная ставка| F[4. Instant Booking (Купить сейчас)]
    
    C -->|Anti-sniping: +5 мин при ставке в конце| G[Определение победителя]
    D -->|Первый акцепт забирает рейс| G
    E -->|Интегральный скоринг: Цена + Рейтинг| G
    F -->|Атомарный лок в Redis| G
```

## 2. Спецификация аукционных моделей

### 2.1. Реверсивный английский аукцион (Reverse English Auction)
Самый распространенный тип торгов на открытой бирже грузов:
- **Начальная цена ($P_{\text{start}}$)**: Максимальная ставка, которую готов заплатить грузовладелец (Ceiling Rate).
- **Шаг торга (Tick Size)**:
  - При ставке до 100 000 ₽: минимальный шаг **1 000 ₽**.
  - При ставке выше 100 000 ₽: минимальный шаг **2 000 ₽** (или $1\%$).
- **Правило защиты от снайпинга (Anti-sniping / Soft Close)**:
  - Если новая лучшая ставка поступает в последние **120 секунд** до завершения таймера, время аукциона автоматически продлевается на **+5 минут**.
  - Максимальное число автопродлений: **6 раз** (суммарно не более 30 минут сверх регламента).
- **Определение победителя**: Заказ автоматически переходит перевозчику, предложившему наименьшую ставку на момент истечения таймера.

### 2.2. Голландский аукцион на повышение (Dutch Reverse Auction)
Применяется для сверхсрочных грузов («горящий рейс», срыв подачи предыдущим перевозчиком):
- **Логика**: Поиск перевозчика в условиях жесткого дефицита времени до окна погрузки ($< 12$ часов).
- **Динамика цены**:
  - Начальная цена выставляется на уровне операционной себестоимости (Floor Rate, например 85 000 ₽).
  - Таймер шага: **каждые 15 минут** цена автоматически повышается на фиксированный шаг $\Delta P$ (+5 000 ₽) вплоть до потолка $P_{\text{max}}$.
- **Механика победы**: Первый перевозчик, нажавший кнопку **«Забрать рейс по текущей цене»**, немедленно побеждает в аукционе. Торги мгновенно останавливаются.

### 2.3. Закрытый корпоративный тендер (Sealed-Bid Tender)
Применяется ритейлерами и крупными промышленными предприятиями для распределения пула регулярных маршрутов на месяц/квартал:
- **Слепая подача (Blind Bidding)**: Перевозчики подают ставки в закрытом виде. Ни один участник не видит ставок конкурентов.
- **Интегральная формула ранжирования победителей**:

$$\text{Final Score} = 0.55 \times S_{\text{price}} + 0.25 \times S_{\text{trust}} + 0.20 \times S_{\text{fleet}}$$

- $S_{\text{price}} = \frac{P_{\text{min\_tender}}}{P_{\text{carrier}}} \times 100$ (Нормированный балл цены).
- $S_{\text{trust}}$: Trust Score компании (0..100) из модуля верификации СБ.
- $S_{\text{fleet}}$: Обеспеченность собственным автопарком требуемого типа (ПТС в реестре).

### 2.4. Мгновенное бронирование (Instant Booking / Buy Now)
- Грузовладелец фиксирует твердую ставку «Без торга».
- Любой верифицированный перевозчик с рейтингом не ниже требуемого уровня (Tier Gold / Silver) может забронировать рейс за 1 клик.

## 3. Защита от состояния гонки: Redis Redlock & Lua-скрипт ставок

Для исключения ситуаций Double Booking и race condition при одновременной подаче ставок миллисекунда-в-миллисекунду используется атомарный Lua-скрипт в Redis:

```lua
-- KEYS[1]: load:auction:<load_id>
-- ARGV[1]: new_bid_rub
-- ARGV[2]: carrier_org_id
-- ARGV[3]: min_tick_rub
-- ARGV[4]: current_timestamp

local auction = redis.call('HMGET', KEYS[1], 'status', 'lowest_bid', 'leading_carrier', 'ends_at')
local status = auction[1]
local lowest_bid = tonumber(auction[2])
local ends_at = tonumber(auction[4])

if status ~= 'ACTIVE' then
    return {err = "AUCTION_NOT_ACTIVE"}
end

local new_bid = tonumber(ARGV[1])
local tick = tonumber(ARGV[3])
local now = tonumber(ARGV[4])

if now > ends_at then
    return {err = "AUCTION_EXPIRED"}
end

-- Проверка шага торга (ставка должна быть минимум на Tick ниже текущей)
if lowest_bid and (new_bid > (lowest_bid - tick)) then
    return {err = "BID_TOO_HIGH", lowest_bid = lowest_bid}
end

-- Обновление лидирующей ставки
redis.call('HMSET', KEYS[1], 'lowest_bid', new_bid, 'leading_carrier', ARGV[2], 'last_bid_at', now)

-- Проверка Anti-sniping: если осталось менее 120 секунд, продлеваем на 300 секунд
local remaining_time = ends_at - now
if remaining_time < 120 then
    ends_at = ends_at + 300
    redis.call('HSET', KEYS[1], 'ends_at', ends_at)
    return {ok = "BID_ACCEPTED_AND_EXTENDED", new_ends_at = ends_at}
end

return {ok = "BID_ACCEPTED", new_ends_at = ends_at}
```

## 4. Гарантии и финансовое обеспечение ставок (Bid Bonds)

1. **Блокировка обеспечения**:
   - При подаче встречного предложения у перевозчика на балансе или кредитном лимите временно холдируется гарантийный депозит в размере **2% от ставки** (или минимум 2 500 ₽).
2. **Разморозка**:
   - Депозит мгновенно возвращается при перебитии ставки конкурентом или при отмене аукциона грузовладельцем.
3. **Штраф за безосновательный отказ (Winner Default)**:
   - Если победитель торгов в течение 2 часов отказывается от подписания договора-заявки, гарантийный депозит списывается в пользу грузовладельца, а рейтинг надежности перевозчика понижается на 15 пунктов.
