# Поведенческий контракт: Электронная очередь склада и управление пандусами (Warehouse Dock Scheduler)

## 1. Визуальные состояния экрана (PlantUML Salt)

### Состояние 1: Диспетчер ворот и расписание тайм-слотов (Dock Gate Schedule)
Оператор склада видит статус всех ворот (погрузка, разгрузка, свободен, простой) и живую очередь тягачей на накопительной парковке.

![Warehouse Dock State 1](images/warehouse-dock-state1.svg)

### Состояние 2: Электронное табло вызова ТС к пандусу (Driver Calling Display)
Информационное табло для водителей на территории склада: номер тягача, марка, назначенные ворота и обратный отсчет времени на заезд.

![Warehouse Dock State 2](images/warehouse-dock-state2.svg)

### Состояние 3: Оформление акта сверхнормативного простоя (Detention Penalty Act)
При задержке погрузки свыше нормативных 4 часов система автоматически рассчитывает сумму штрафа и формирует акт простоя в пользу перевозчика.

![Warehouse Dock State 3](images/warehouse-dock-state3.svg)

## 2. Детальные поведенческие контракты

- **Автоматический вызов на пандус**:
  - Когда ворота освобождаются (предыдущий рейс завершил оформление ЭТрН), система берет следующий тягач из очереди по времени тайм-слота.
  - На табло загорается зеленый номер ТС, а водителю отправляется SMS: «Заезжайте на ворота №3. Время на постановку: 10 мин».
- **Контроль времени простоя (Detention Tracking)**:
  - Время отсчитывается с момента подтверждения заезда через КПП (фотофиксация номера LPR камерой).
  - Нормативное время: 4 часа для стандартного автопоезда 20т (если иное не указано в договоре-заявке).
  - При превышении 4 часов таймер становится красным, а в биллинговый модуль начинает начисляться поминутная компенсация за простой.
