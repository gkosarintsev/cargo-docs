# Поведенческий контракт: Отслеживание доставки грузовладельцем (Shipper Live Tracking)

## 1. Визуальные состояния экрана (PlantUML Salt)

### Состояние 1: Штатное движение рейса (On Schedule)
Отображение положения тягача на карте, прогресс-бара по точкам и динамического расчета ETA с запасом времени.

![Shipper Tracking State 1](images/shipper-tracking-state1.svg)

### Состояние 2: Алерт критической задержки (Emergency Stop >2h)
Если ТС остановилось на трассе более чем на 120 минут вне плановых стоянок, карточка подсвечивается красным, выводится предупреждение и кнопки быстрого реагирования.

![Shipper Tracking State 2](images/shipper-tracking-state2.svg)

### Состояние 3: Боковая шторка детальной телеметрии и термограммы (Telemetry Drawer)
Грузовладелец скоропортящихся или дорогостоящих грузов открывает шторку с показаниями термодатчиков в кузове, датчиков дверей и бортовой сети.

![Shipper Tracking State 3](images/shipper-tracking-state3.svg)

## 2. Детальные поведенческие контракты

- **Интерполяция маркера на карте**:
  - Координаты приходят по WebSocket (`gps_position_updated`) с частотой раз в 10–30 секунд.
  - Положение маркера на карте перемещается плавно с CSS/JS анимацией, рассчитывая азимут поворота иконки грузовика.
- **Расчет и пересчет ETA**:
  - Сервис отслеживания постоянно пересчитывает прогнозное время прибытия с учетом текущей скорости и истории движения.
  - Если ETA превышает плановое окно погрузки/разгрузки более чем на 60 минут, генерируется событие `DelayWarning`. При задержке >120 мин статус меняется на `DELAY_ALERT`.
- **Контроль геозон**:
  - При пересечении радиуса склада (300м) отправляется событие `GeofenceEntered`, и статус автоматически переводится в `AT_PICKUP` / `AT_DELIVERY`.
