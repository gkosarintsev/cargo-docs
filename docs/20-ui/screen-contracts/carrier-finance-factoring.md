# Поведенческий контракт: Финансовый кабинет перевозчика и Факторинг (Carrier Finance & Factoring)

## 1. Визуальные состояния экрана (PlantUML Salt)

### Состояние 1: Финансовый баланс и реестр счетов (Receivables Registry)
Перевозчик видит счета с длительной отсрочкой платежа (15–45 дней) и доступный кредитный лимит факторинга без залога.

![Carrier Finance State 1](images/carrier-finance-state1.svg)

### Состояние 2: Заявка на экспресс-финансирование (Factoring Request Modal)
Расчет точной суммы к выплате с вычетом комиссии фактора (2.1–2.8%), подписание договора цессии (уступки права требования) через КЭП.

![Carrier Finance State 2](images/carrier-finance-state2.svg)

### Состояние 3: Мгновенное исполнение выплаты (Instant Settlement Confirmation)
Уведомление об успешном банковском переводе через СБП B2B с выгрузкой платежного поручения с синей отметкой банка.

![Carrier Finance State 3](images/carrier-finance-state3.svg)

## 2. Детальные поведенческие контракты

- **Онлайн-валидация дебитора**:
  - Факторинг доступен только по подтвержденным PoD (где накладная подписана обеими сторонами без открытых актов расхождений).
  - Заказчик должен иметь рейтинг надежности не ниже `Silver`.
- **Автоматическая цессия**:
  - При подписании заявки генерируется трехстороннее уведомление об уступке требования по 382 ГК РФ.
  - По факту наступления плановой даты оплаты заказчик переводит средства напрямую факторинговой компании.
- **Интеграция с банковскими шлюзами**:
  - Интеграция с API СберФакторинг / Альфа-Банк.
  - Средства зачисляются за 15–60 минут в автоматическом режиме 24/7.
