# Поведенческий контракт: Мобильное рабочее место водителя (Driver Mobile App)

## 1. Визуальные состояния экрана (PlantUML Salt)

### Состояние 1: Главный экран текущего рейса (Trip Briefing)
Отображение маршрута, контактных данных склада, временного окна погрузки и кнопки запуска Яндекс.Навигатора с параметрами для грузового транспорта.

![Driver Trip State 1](images/driver-trip-state1.svg)

### Состояние 2: Подтверждение прибытия на склад (Geofence Check-in)
При подъезде к складу водитель нажимает «Я прибыл». Система валидирует координаты GPS устройства (радиус не более 300 метров от ворот).

![Driver Trip State 2](images/driver-trip-state2.svg)

### Состояние 3: Окончание погрузки и подписание ЭТрН (Loading Sign-off)
Фиксация номера пломбы, показаний температуры и подписание Титула 2 ЭТрН простой электронной подписью (ПЭП) через СМС-код.

![Driver Trip State 3](images/driver-trip-state3.svg)

## 2. Детальные поведенческие контракты

- **Геопроверка чек-ина (Geofencing)**:
  - Кнопка «Я прибыл» сверяет GPS смартфона с полигоном склада.
  - Если водитель дальше 300м, выводится предупреждение: «Вы находитесь слишком далеко от склада. Дождитесь подъезда к КПП».
- **Интеграция с навигацией**:
  - Клик по кнопке «Запустить Яндекс.Навигатор» генерирует глубокую ссылку (`yandexnavi://build_route_on_map?lat_to=...&lon_to=...`) с грузовым профилем (исключение мостов с ограничением по высоте и тоннажу).
- **Экстренная кнопка SOS**:
  - Нажатие SOS немедленно транслирует координаты в диспетчерский пульт с приоритетом P0, поднимая рейс в красный топ списка и инициируя обратный звонок диспетчера.
- **Индикация Offline-режима (Offline-First Sync Badge)**:
  - При отсутствии связи в шапке приложения появляется янтарный баннер: `[⚠️ Оффлайн-режим: N точек в очереди SQLite]`. Все действия (фотофиксация пломбы, отметка прибытия) разрешены локально с отметкой локального таймстемпа.
  - При появлении сети баннер на 3 секунды сменяется на зеленый пульсирующий бейдж: `[✅ Сеть активна: 100% данных выгружено]`.
