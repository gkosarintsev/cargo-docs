# Поведенческий контракт: Экран поиска и фильтрации грузов

## Визуальное состояние экрана в разные моменты времени (PlantUML Salt)

### 1. Просмотр списка результатов (Idle State)
Пользователь настроил фильтры, сервер вернул результаты.

![Load Search Results](images/load-search-state1.svg)

### 2. Уведомление о новых грузах (WS Push Notification)
Пока пользователь смотрел список, в системе появились новые грузы, подходящие под его фильтры. По WebSocket пришел Push, и появился "плавающий" бейдж сверху, не сбивая текущий скролл.

![Load Search New Matches](images/load-search-state2.svg)

## Детальные поведенческие контракты
- **Фильтрация**: Изменение любого фильтра вызывает обновление списка без перезагрузки страницы (Debounce 300-500ms). Старый список становится полупрозрачным (opacity 0.6) + spinner.
- **Бесконечный скролл (Infinite Scroll)**: При достижении 80% высоты списка отправляется запрос за следующей страницей (по `cursor`). Позиция скролла сохраняется.
- **Real-time бейдж**: Плавающая кнопка `Показать +3 новых груза` позволяет загрузить свежие карточки наверх списка по клику (Pull-to-top).
