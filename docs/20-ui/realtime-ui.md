# Архитектура реактивного фронтенда (Real-time UI)

## Управление WebSocket-соединением
- **Single WS Client**: Одно глобальное соединение на вкладку браузера (через Redux/Zustand middleware).
- **Auto-Reconnect**: Экспоненциальный backoff при обрыве соединения (1s, 2s, 4s, 8s).
- **Offline Queue**: Очередь событий и мутаций при потере сети, синхронизация после восстановления (sync up).

## Optimistic Updates (Оптимистичные обновления)
- При действии пользователя (например, лайк оффера) локальное состояние UI обновляется мгновенно.
- Если бэкенд возвращает 5xx или Timeout, происходит откат (Rollback) локального состояния до предыдущего с показом Toast-уведомления "Ошибка сервера. Действие отменено".

## Уведомления
- **Toast-уведомления**: Неблокирующие уведомления для диспетчеров со звуковым сигналом (опционально) для критичных событий (срыв сроков, новые ставки).
