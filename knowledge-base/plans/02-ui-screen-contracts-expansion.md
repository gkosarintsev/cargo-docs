# План разработки поведенческих контрактов и UI-интерфейсов платформы (Screen Contracts Roadmap)

## 1. Цель и подход
Цель — спроектировать исчерпывающую матрицу экранов логистической платформы со всеми ключевыми ролями и промежуточными состояниями (Empty, Active, Drawer/Modal, Loading/Calculating, Alert/Incident, Success/Completed) в виде **Wireframe-контрактов (PlantUML Salt)** и поведенческих спецификаций до начала фронтенд-разработки.

Все схемы созданы как `.puml` в `docs/20-ui/screen-contracts/images/`, компилируются в `.svg` через GitHub Actions workflow, а в спецификациях `.md` зафиксированы:
- Визуальные состояния экрана (PlantUML Salt wireframes).
- Поведенческие контракты (валидация, дебаунсы, WebSocket-события, идемпотентность, optimistic UI).
- Маппинг на эндпоинты OpenAPI и доменные модели.

- [x] `[TASK-020]` **Детализация карточки груза и торга (`docs/20-ui/screen-contracts/load-details-and-negotiation.md`)**:

  - `load-details-state2.puml`: Поступили конкурирующие офферы (Таблица ставок, рейтинг перевозчиков, бейджи надежности).
  - `load-details-state3.puml`: Модальное окно встречного предложения (Counter-Offer modal с шагом ставки).
- [x] `[TASK-021]` **Экран отслеживания активных доставок (`docs/20-ui/screen-contracts/shipper-tracking-view.md`)**:
  - `shipper-tracking-state1.puml`: Штатный режим (Прогресс-бар маршрута, ETA, геопозиция на карте).
  - `shipper-tracking-state2.puml`: Алерт задержки (Отклонение > 2ч, прогнозируемое опоздание на разгрузку).
  - `shipper-tracking-state3.puml`: Drawer с деталями водителя, датчиками температуры рефрижератора и кнопкой экстренной связи.
- [x] `[TASK-022]` **Экран ЭДО, закрывающих документов и претензий (`docs/20-ui/screen-contracts/shipper-documents-and-claims.md`)**:
  - `documents-claims-state1.puml`: Реестр документов рейса (ЭТрН, ТТН, доверенности, статус КЭП).
  - `documents-claims-state2.puml`: Формирование коммерческого акта расхождений (Торг-2 при повреждении или недостаче).
  - `documents-claims-state3.puml`: Успешная фиксация претензии и заморозка выплаты из Escrow.
