# План углубления документации: РТО водителей, аукционные алгоритмы и нагрузочные профили

## 1. Контекст
Для достижения абсолютной отраслевой полноты логистической платформы требуются специализированные спецификации:
1. **Режим труда и отдыха (РТО) водителей по Приказу Минтранса № 424 и тахографы СКЗИ/ЕСТР**: Алгоритм учета обязательных стоянок в маршрутизаторе (Routing Engine) и валидация ddd-файлов.
2. **Аукционные механики и биржевые алгоритмы маркетплейса**: Реверсивный английский аукцион, голландский аукцион с автоповышением ставки, защита от снайпинга (Anti-sniping).
3. **Каскадный протокол уведомлений и связь**: Push -> SMS -> Голосовой IVR с гарантией доставки P0 алертов.
4. **Профиль нагрузочного и стресс-тестирования k6**: Сценарии 50 000 телеметрических пакетов/сек и пиковые биржевые торги.
5. **Интерактивный симулятор тахографа и РТО в веб-приложении**: Визуализация работы бортового тахографа с контролем 4.5-часового лимита вождения и таймером отдыха.

## 2. Задачи плана

- [x] `[TASK-060]` **Спецификация РТО водителей и тахографического контроля (`docs/09-fleet/driver-work-rest-schedule.md`)**:
  - Нормы Приказа Минтранса РФ № 424 (9ч вождения/день, 45 мин перерыв каждые 4.5ч).
  - Алгоритм вставки стоянок в дорожный граф OSRM/Valhalla.
  - Формат разбора файлов тахографа `.ddd` (карта водителя с блоком СКЗИ).
- [x] `[TASK-061]` **Аукционные алгоритмы маркетплейса (`docs/06-marketplace/auction-mechanisms.md`)**:
  - Реверсивный английский аукцион с шагом торга (Tick Size) и автопродлением (+5 мин).
  - Голландский аукцион для горящих грузов (динамическое повышение цены каждые N минут).
  - Защита от race conditions через распределенные блокировки Redis Redlock.
- [x] `[TASK-062]` **Каскадный протокол доставки уведомлений (`docs/13-communication/notification-cascades.md`)**:
  - Многоуровневый каскад: WebSocket -> FCM/APNs -> SMS -> IVR Робот.
  - Очереди RabbitMQ / Redis Streams для отслеживания доставки и квитанций прочтения.
- [x] `[TASK-063]` **Профиль нагрузочного и хаос-тестирования k6 (`docs/21-testing/load-tests.md`)**:
  - Готовые скрипты k6 для симуляции 50 000 pings/sec и биржевых flash mob.
  - Метрики устойчивости к отказам и критерии прохождения (Quality Gates).
- [x] `[TASK-064]` **Интерактивный симулятор тахографа водителя в UI (`src/components/prototypes/TachographSimulator.tsx`)**:
  - Реалистичная панель цифрового тахографа (СКЗИ): таймер вождения 04:30, переключение режимов (Руль / Молоточки / Кровать), предупреждение о необходимости отстоя и штрафах.
